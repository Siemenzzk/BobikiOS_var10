# ОСРВ — Вариант 10

Курсовая работа по курсу **«Архитектура программных систем»**

## Суть проекта

Реализация модели операционной системы реального времени на языке C.

## Характеристики варианта

| Параметр | Значение |
|---|---|
| Тип планировщика | Плоский |
| Алгоритм планирования | Preemptive RMA |
| Управление ресурсами | HLP (Highest Locker Protocol) |
| Управление событиями | Системные события |
| Обработка прерываний | Нет |
| Макс. количество задач | 32 |
| Макс. количество ресурсов | 16 |
| Макс. количество событий | 16 |
